VELORA v2 — Free static online store
========================================
Files:
index.html  = website
style.css   = design
script.js   = products, search, filters, cart and WhatsApp checkout

IMPORTANT:
1. In script.js, replace https://wa.me/?text= with your own WhatsApp number.
   Example: https://wa.me/923001234567?text=
2. Product prices/names can be edited in the products array.
3. The current product visuals are lightweight placeholders so the site stays free and fast.
4. For real online payments, connect a payment provider later.

FREE HOSTING:
GitHub Pages / Cloudflare Pages can host these static files for free.
